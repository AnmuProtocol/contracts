# Privacy contracts

`honk/CreatorAuthHonkVerifier.sol` is the UltraHonk verifier generated by Barretenberg `6.0.0-nightly.20260916` with `-t evm`. The only edit after generation is the contract name. Regenerate it with `zk/creator_auth/write_evm_verifier.sh`.

`CreatorVerifier` checks the seven public inputs, then calls that generated contract. It does not accept a proof by returning true on its own.

`honk/ClaimHonkVerifier.sol` is the generated UltraHonk verifier for `zk/private_claim`. `ClaimVerifier` checks the seven claim public inputs, then calls that contract.
